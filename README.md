# Advoga BR - demo

Site estático (HTML + CSS, sem JavaScript, sem build).

## Estrutura
advoga-br/
  index.html      página inteira
  favicon.svg     ícone da aba
  robots.txt      bloqueia indexação (DEMO; remover ao publicar a versão final)
  img/            fotos dos advogados

## Subir na Vercel
Na pasta: npx vercel
(Framework preset: Other. Sem build command. Output: raiz.)

## Antes da versão final
- Trocar tudo que está em [colchetes] no index.html
- Trocar o endereço do mapa (q=...) e do botão "Abrir no Google Maps"
- Links do Instagram e Facebook (href="#")
- Remover a linha <meta name="robots" content="noindex, nofollow"> e o robots.txt
- Hospedagem de site pago: ver termos de uso comercial do provedor
